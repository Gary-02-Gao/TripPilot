# 成果与验证

## 训练与评测设置

基座为 Qwen3-0.6B，采用三阶段顺序合并 LoRA。评测使用顺序化协议 v2：200 条对话、378 个 Assistant 节点，含 169 个工具目标与 209 个非工具目标。每个节点给定标准历史上下文独立预测。

## 实验结果

| 指标 | 计数 | 结果 |
| --- | ---: | ---: |
| 调用工具/回复决策正确 | 352 / 378 | 93.12% |
| 工具名序列正确 | 163 / 169 | 96.45% |
| 参数严格匹配 | 155 / 169 | 91.72% |
| 工具调用严格匹配（工具名与参数同时正确） | 155 / 169 | 91.72% |
| 预测工具输出 JSON 合法 | 183 / 183 | 100% |
| 非工具目标产生非空、非工具回复 | 189 / 209 | 90.43% |

## 评分方法

- 工具名、参数及完整调用均在 169 个工具目标上评分。
- JSON 合法率统计全部 183 个预测工具输出的格式有效性。
- 非空回复率统计 209 个非工具目标的输出情况；回复内容质量需单独评测。
- 当前成绩为标准历史上下文下的节点评测；自主多轮任务成功率尚未评测，需另行测试。
- 历史 Base 对照为顺序化 v1，当前最终结果为 v2；两套协议分别记录。

## 证据与复算

| 文件 | 内容 |
| --- | --- |
| `public-evaluation.json` | 公开计数、真实归档预测与来源哈希 |
| `evaluation-audit.json` | 逐节点评分判定及预测文本哈希 |
| `model-chain.json` | 三个适配器的合并顺序与权重哈希 |
| `training-summary.json` | 最终训练样本数、LoRA 参数及数据哈希 |
| `frontend-verification.json` | 11 项浏览器检查结果 |
| `source-manifest.json` | 精选实现的来源及交付哈希 |
| `verify_results.py` | 按节点汇总复算评分计数 |

运行 `python3 verify_results.py` 可复算逐节点评分。完整模型重评需要匹配的基座、顺序合并适配器及对应评测数据。包根目录 `MANIFEST.sha256` 提供交付文件校验。

2026-09-23 提交前审查补充了评测脚本的异常 JSON 防护，并要求整体解析有效才计为工具调用严格匹配；历史评测数据与指标保持原始归档内容，本次未重新执行模型推理。
