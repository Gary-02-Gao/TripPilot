# TripPilot · 基于 Qwen3 LoRA 的旅行工具调用智能体

**高士奇 · 项目作品集**

围绕小模型 Function Calling，完成训练数据规范化、依赖式工具协议、LoRA 微调、分项评测与可视化工作台。

## 核心成果

- **工具调用微调**：基于 Qwen3-0.6B 完成 LoRA 微调；顺序化协议 v2 的 169 个工具目标中，工具名准确率 **96.45%（163/169）**，工具名及参数严格匹配率 **91.72%（155/169）**。
- **可学习的数据协议**：统一城市名称、参数格式和工具依赖顺序，将“攻略结果 → 天气参数”显式串联；最终训练阶段使用 **3,048 条顺序化样本**。
- **精确的监督范围**：仅最后一条 Assistant 消息参与 Loss，采用 LoRA rank 32、BF16 与双卡 DDP；保留三阶段适配器合并顺序、训练记录与权重哈希。
- **可观察的工具流程**：工作台支持需求补全、工具轨迹、参数展开、归档模型预测与评测查看；当前 **14 项单元测试通过**，保留原始 **11 项浏览器检查**记录，最新核验见 [本地环境验证](本地环境验证.md)。

评测设置：**200 条对话、378 个 Assistant 节点**，在标准历史上下文下独立预测各节点。完整指标与评分方法见 [成果与验证](02_成果与验证/README.md)。

## 快速体验

演示只需 Python 3.9+ 标准库。在仓库根目录执行：

```bash
python3 03_核心代码/demo_server.py --host 127.0.0.1 --port 8091
```

打开 <http://127.0.0.1:8091>。普通对话使用离线控制器与模拟工具，LoRA 样本来自历史评测，不是实时模型推理。macOS 双击启动与虚拟环境重建见 [本地运行说明](本地运行说明.md)。
